# Mantine 桌面交互预览

这是用户于 2026-11-09（JST）确认的桌面 UI 基准，使用 React 19、Mantine 9.8 与 Tabler Icons。实现遵循 [桌面端 UI 规范](../../desktop/UI_DESIGN.md)。所有设备、应用、文件与任务均为演示数据，交互不会访问手机、执行命令或修改电脑文件（明确点击导出时仅下载演示记录）。

- **直接打开**：[单文件 HTML](../desktop-mantine-mock.html)，无需网络或启动服务。
- 页面：设备概览、解锁 Bootloader、应用管理、文件传输、终端与日志、设置。
- 可体验：深浅色、设备切换与断连、应用搜索/筛选/多选、文件传输演示、解锁适配检查演示、终端预设响应、日志抽屉。
- 快捷键：`⌘/Ctrl + K` 打开工具搜索，`Esc` 关闭弹窗与抽屉。

## 重新构建

在本目录执行 `npm ci`，随后 `npm run build`。`dist/index.html` 是内嵌全部脚本、样式和图标的输出，构建脚本自动同步至上一级的 `desktop-mantine-mock.html`，可直接打开。

源文件用于维护已确认的 UI 基准；改变导航、主色体系、页面层级或主操作时先更新规范与预览并获得用户确认。该预览不代表桌面版本、首版功能范围或设备支持已经确定。
