参考与设计说明

以现有 Android 客户端为基础，保留「权限服务、应用授权、设备诊断、设置」四个入口。

  • miuix 官方示例浅灰背景、白色圆角分组、大标题、蓝色主操作和单色底栏。
  • KernelSU Manager · HomeMiuix.kt状态卡优先。采用浅绿连接状态卡与单一主操作，明确 Shell 身份。
  • GhostLock · GhostlockUI.kt折叠信息层级、分组设置与底部弹层，避免在首页堆积操作说明。
  • Shizuku · home_start_wireless_adb.xml保留无线调试和电脑 ADB 两个激活入口，离线时将激活设为主操作。

视觉规格：背景 #F6F6F6、卡片 #FFFFFF、正文 #17191C、辅助文字 #777B83、主色 #3482FF、连接状态 #E0F5E7。中文优先使用系统字体；12px 页面边距、20px 分组圆角、30px 页面标题。
