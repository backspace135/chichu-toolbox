# 桌面端文档

Windows、macOS 共用 Tauri 桌面工程，macOS 仅支持 Apple Silicon。技术栈和 Mantine UI 已确认，正式工程尚待初始化。

总任务：[桌面端总 issue #10：强制解锁 Bootloader + Android 玩机工具箱](https://github.com/backspace135/chichu-toolbox/issues/10)。

## 当前待决策

- 最低 Windows/macOS 版本，以及 Windows x64 正式支持目标。
- 固定基线全部功能保留；逐项首版/后续批次与独立桌面版本号待确认，部分版本不关闭M5/#10。
- 可测试的设备与精确固件、首个实际采用的强解方案。
- 初始化依赖版本已固定为工程输入；锁文件与双平台首次构建、工具打包及签名发布配置仍待落地验证。
- GPL复用后的项目发布许可/对应源码安排、五色主题与既有主色规范兼容、Wi-Fi修复时区/NTP行为的产品处理。

## 执行入口

M0a=#14盘点/复用许可+#15平台工具链+#16每日跟踪；M0b=#17强解可行性；M1=#18工程+#19连接；M2=#20任务；M3=#21识别推荐；M4=#22首条自动强解；M5=#23–#30全部功能迁移；M6=#31发布验收。M4依赖M0b+M2+M3，普通工程不必等M0b；完整总目标还要求M5全部双平台通过。旧D0–D7迁移索引见开发文档。

源码自报1.0.0不等于桌面版本。盘点不构成Windows/macOS支持证据；无线配对/收藏未见可见入口，已有tcpip/usb脚本语义及未接线桥接接口分开记录。目录授权和凭据清理必须有桌面等价，不能清其他ADB工具密钥。GitHub回填仅准备本地映射，尚未写远端。

Android v0.1.0 仅获取临时 Root；桌面计划属于后续阶段。UI mock 中出现的设备和功能不代表已经实现或受支持。
