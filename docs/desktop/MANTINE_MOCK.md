## 视觉与结构

- 浅色基底：工作区 `#F5F7FA`、分组 `#FFFFFF`、侧栏 `#F9FAFC`、正文 `#25324A`、辅助文字 `#626F83`、主操作蓝 `#2F6CDA`。
- 深色使用独立工作区、分组和文字颜色，主操作保持蓝色。
- 使用系统无衬线中文字体，标题突出、表格紧凑；不加载在线字体。
- 固定工作侧栏与顶部设备选择，主内容随页面变化；任务记录通过抽屉查看。
- 首页以设备状态为中心，手机示意图为纯 CSS 插画；快捷工具、解锁入口、设备详情与最近操作有不同层级。
- Mantine 原生组件承担按钮、表格、Checkbox、SegmentedControl、菜单、弹窗、抽屉、输入、进度、开关与主题；业务布局用少量自定义样式。

## 可体验内容

1. **设备概览**：设备选择、断连与重连、设备详情、安装和截图弹窗。
2. **解锁 Bootloader**：分步流程、适配检查演示、未接入方案与候选方案两种结果。
3. **应用管理**：名称/包名搜索、类型与冻结筛选、多选、冻结/解冻、详情与提取演示。
4. **文件传输**：演示目录浏览、发送/接收进度与记录。
5. **终端与日志**：预设命令响应、任务记录、导出本地演示记录。
6. **设置**：深浅色、紧凑模式、连接与记录偏好开关。

`⌘/Ctrl + K` 打开工具搜索；`Esc` 关闭弹窗。所有设备信息、版本、应用、文件与结果都是示例，不访问设备或执行解锁。
