# macOS 客户端

macOS 与 Windows 共用 [桌面工程](../desktop/README.md)，技术栈为 **Tauri 2 + React + TypeScript + Rust**。

**仅支持 Apple Silicon 原生 arm64**（`aarch64-apple-darwin`），不提供 Intel 构建或 universal 包，随包工具不以 Rosetta 为运行前提。

本目录保留为 macOS 平台说明入口。当前待开发，最低系统版本与构建命令在工程初始化时确定。

参见 [桌面端技术栈决定](../../docs/desktop/TECH_STACK.md)、[仓库布局](../../docs/REPOSITORY_LAYOUT.md)与 [项目总览](../../README.md)。
